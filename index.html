How it works

  • IDs deterministically map to a set of types using a fast PRNG. This gives a virtual space of billions of items & components without storing them.
  • Each type has weaknesses. If your crafted item includes a type that the target is weak to, you win.
  • Use the search box to filter visible components by type or numeric ID. Use New Page to generate a different sample page of components.
